# 🎙️ Verbatim
**Transcrivez vos réunions et obtenez des comptes-rendus rédigés, sans que rien ne quitte votre ordinateur.**

Application Windows : enregistrement ou import audio → transcription Whisper → compte-rendu rédigé par une IA qui tourne **sur votre PC**. Pas de compte, pas d'abonnement, aucun envoi en ligne.

📥 **Télécharger** : https://github.com/Netapick/verbatim/releases/latest
📖 Présentation complète : <https://github.com/Netapick/verbatim/blob/main/docs/PRESENTATION.md>

https://raw.githubusercontent.com/Netapick/verbatim/main/docs/screenshots/01-reunions.png

=== MESSAGE 2 ===
## ✨ Ce que fait Verbatim
• **Enregistrer** le micro, le son du PC (visio, vidéo) ou les deux, avec pause et niveaux en direct
• **Importer** un audio (mp3, m4a, ogg, flac, wav…) ou une transcription (txt, srt, vtt)
• **Transcrire** avec Whisper en local, sur CPU ou GPU (AMD ROCm/Vulkan, NVIDIA CUDA)
• **Rédiger** le compte-rendu avec Qwen (llama.cpp) : résumé, points abordés, décisions, actions, prochaines étapes
• **Préparer** ses réunions : objectif, ordre du jour chronométré, questions
• **Glossaire** de sigles métier transmis à Whisper et à l'IA
• **Exporter** en .txt, .srt, .vtt, .json, .md ou audio
• Thème clair / sombre

=== MESSAGE 4 ===
## 🛠️ Installation
**1.** Téléchargez `Verbatim_0.2.1_x64-setup.exe` (≈ 3 Mo, en français, sans droits administrateur)
**2.** L'installateur détecte votre carte graphique et installe seul les accélérations : ROCm (≈ 430 Mo) pour une Radeon RX 7000, CUDA (≈ 685 Mo) pour NVIDIA, en plus du pack de base (≈ 61 Mo)
**3.** Dans **Réglages**, choisissez un modèle de transcription et, si vous voulez, un modèle de rédaction (aucun n'est livré)

**4.** Mises à jour automatiques depuis GitHub (désactivables dans Réglages › Connexions)

*Windows x64 · pas de diarisation pour l'instant · captures avec réunions fictives*
